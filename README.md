# TempFile
Псевдокод:

```
ПРОГРАММА ВременноеСохранениеФайла:
    НАЧАТЬ
        // Создать сканер для чтения ввода пользователя
        scanner = новый Сканер(System.in)
        
        // Прочитать URL от пользователя
        line = scanner.следующаяСтрока()
        
        // Создать объект URL из введенной строки
        url = новый URL(line)
        
        // Открыть поток для чтения данных по URL
        input = url.открытьПоток()
        
        // Создать временный файл с автоматически сгенерированным именем
        tempFile = Files.создатьВременныйФайл(null, null)
        
        // Прочитать все байты из входного потока и записать их во временный файл
        данные = input.прочитатьВсеБайты()
        Files.записать(tempFile, данные)
        
        // Закрыть входной поток (в оригинальном коде используется try-with-resources)
        input.закрыть()
    КОНЕЦ
```

Пояснение алгоритма:

1. Ввод URL: Пользователь вводит строку с URL-адресом
2. Создание URL-объекта: Преобразование строки в объект URL для работы с сетевыми ресурсами
3. Открытие потока: Установка соединения и получение входного потока для чтения данных
4. Создание временного файла:
   · null, null означает, что имя файла и расширение будут сгенерированы автоматически
   · Файл создается в системной временной директории
5. Копирование данных: Чтение всех данных из сетевого потока и запись их во временный файл

Особенности:

· Временный файл автоматически получает уникальное имя
· Файл создается в системной временной папке (например, /tmp в Linux или C:\Users\...\AppData\Local\Temp в Windows)
· Программа загружает файл из интернета и сохраняет его локально во временной директории
